GDGoC-CTU WEBSITE — V4
========================

This version follows the two reference screenshots:
- The gray navigation/header from the first screenshot
- The Team, Events, Partners, Captured Moments, and CTA layout from the second screenshot
- Responsive behavior for laptop, tablet, and mobile

IMAGE LOCATIONS
---------------
Put your own images inside the "assets" folder:

1. Header picture:
   assets/header-photo.jpg

2. Team:
   assets/team-photo.jpg

3. Events:
   assets/event-1.jpg
   assets/event-2.jpg
   assets/event-3.jpg

4. Partners:
   assets/partner-1.png
   assets/partner-2.png
   assets/partner-3.png

5. Captured Moments:
   assets/moment-1.jpg
   assets/moment-2.jpg
   assets/moment-3.jpg

The HTML contains comments beside every image location.

IMPORTANT
---------
Do not rename the image files unless you also change the corresponding
src="assets/..." path in index.html.

Images use responsive sizing and object-fit: cover so they do not stretch
when the screen changes size.
